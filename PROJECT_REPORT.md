# Student Performance Management System

## 📌 Project Overview

The **Student Performance Management System** is a Java-based command-line application developed to manage and monitor student academic information.

The system provides a simple way to store and manage **student details, marks, and attendance** in one place. It also calculates percentages and grades, analyzes overall performance, and generates a complete performance report for individual students.

The project demonstrates the practical use of **Java, Object-Oriented Programming, ArrayList, file handling, exception handling, and input validation**.

---

## 🎯 Objectives

* Manage student academic information.
* Store and manage student marks.
* Record and calculate attendance.
* Calculate total marks, percentage, and grades.
* Analyze overall student performance.
* Generate individual student performance reports.
* Store data permanently using text files.
* Reduce manual record keeping.

---

## ⚙️ Modules

### 1. Student Management

Allows the user to:

* Add student details
* View student details
* Search for students
* Update student information
* Delete student records

### 2. Marks Management

The system stores marks for:

* Mathematics
* Java
* Operating Systems

It calculates:

* Total marks
* Percentage
* Grade

### 3. Attendance Management

This module:

* Stores attendance records
* Calculates attendance percentage
* Checks attendance eligibility

### 4. Performance Analysis

The system analyzes marks and attendance and classifies students into:

* Excellent
* Good
* Average
* Needs Improvement

### 5. Report Generation

Generates a complete performance report containing:

* Student details
* Subject-wise marks
* Total marks
* Percentage
* Grade
* Attendance percentage
* Overall performance

### 6. File Management

Student, marks, and attendance information are stored in text files.

This allows the data to be loaded again when the application is restarted.

## ▶️ How to Run

### Step 1: Clone the Repository

```bash
git clone <repository-url>
```

### Step 2: Open the Project

Open the project in **Visual Studio Code** or any Java-supported IDE.

### Step 3: Compile the Program

```bash
javac Main.java
```

### Step 4: Run the Program

```bash
java Main
```
